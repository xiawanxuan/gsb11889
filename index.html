与 CSS Grid / Flex 的对比

CSS Grid（auto-fill + 行高对齐）

Grid 是二维网格：行高由该行最高项决定，无法做出"每列独立高度"的瀑布流，更无法表达环形/螺旋。

Flex（flex-wrap）

Flex 是单轴换行：交叉轴按行拉伸对齐，同样无法错位咬合或沿曲线排布。

能力Grid / FlexHoudini Layout Worklet
瀑布流（列独立高度）需 JS 或 masonry 实验特性原生布局阶段实现
任意几何（环形/螺旋）不支持支持（自定义算法）
运行时机—浏览器布局管线内，随固有尺寸变化自动重排
主线程阻塞风险无算法过重会拖慢布局 → 需监控 + 降级
浏览器支持全面Chromium 系；其他需 JS 降级
